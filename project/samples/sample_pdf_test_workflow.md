# Sample PDF Test Workflow

1. Mở ứng dụng, chọn file PDF text-based.
2. Chọn chế độ `Trích xuất toàn bộ nội dung -> Word`.
3. Chọn trang 1 đến 3, nhấn **Bắt đầu**.
4. Kiểm tra file `.docx` và `.json` trong `project/output/`.
5. Chạy lại với PDF dạng scan, bật **OCR nếu PDF Scan**.
6. Chuyển sang chế độ bảng, nhập header theo từng dòng.
7. Nhấn **Bắt đầu**, kiểm tra `.xlsx` và preview bảng.
